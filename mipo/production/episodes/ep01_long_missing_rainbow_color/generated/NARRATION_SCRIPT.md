# Mipo and the Missing Rainbow Color - Narration script

**Voice:** narrator (gentle storyteller) + Mipo + Blue Bird + Bunny + Baby Deer + Little Purple. Narrator: warm, friendly storyteller. Mipo: warm, cheerful young boy (6-7). Friends: small, sweet, distinct. Clear American English, calm pace with pauses for kids to answer.  
**Consistency:** Each character always uses the same ElevenLabs voice (production/voices.json). Never change a character's voice between episodes.

Times are positions on the final 660.0 s timeline. `Must end` is the latest the line may finish before it collides with the next line. Record each line as its own file (`L001.wav` ... `L084.wav`), 2-3 takes each, and keep the best take.

**Learning goals:** Rainbow colors: red, orange, yellow, green, blue, purple; Counting to 5 and to 6; countdown 3-2-1; Naming feelings: sad, scared, brave, happy; Calm-down breathing; Asking for help, helping others, taking turns; Everyone is important; kindness  
**Emotional arc:** sad -> calmer -> hopeful -> brave -> caring -> brave together -> kind -> joyful
